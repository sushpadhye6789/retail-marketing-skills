# Christopher S. Penn

**Lens:** Not every marketing task is a good candidate for AI automation — the right filter is whether a task is time-consuming, repetitive, important, painful, and has sufficient data behind it, not just whether AI is technically capable of attempting it.

## Public framework

Penn (co-founder/Chief Data Scientist at Trust Insights, co-host of the Marketing Over Coffee podcast) has published several practical frameworks for AI adoption discipline rather than AI enthusiasm alone: the **TRIPS framework** scores candidate tasks across five dimensions — Time, Repetitiveness, Importance, Pain, and Sufficient Data — to identify which tasks should actually be handed to AI first, rather than automating whatever's easiest or most novel. Trust Insights' related **6C Data Quality Framework** (data should be clean, complete, comprehensive, chosen, credible, and calculable) addresses the precondition most AI-automation advice skips: AI automation is only as good as the data quality underneath it.

## Retail application

This is a useful discipline check for this repo's own `marketing-loops` skill: before automating a marketing task (a weekly reporting loop, an ad-fatigue check, a content-repurposing pipeline), TRIPS gives a concrete scoring method for whether that task is actually a good automation candidate, rather than automating because the capability exists. The 6C framework is a direct precondition check for any retailer's personalization or analytics automation — bad first-party data quality undermines AI-driven personalization before the AI layer even gets involved.

## Best for / blind spots

**Best for:** Deciding which marketing tasks to automate first rather than automating indiscriminately; auditing whether a data source is actually good enough to build AI automation on top of.
**Blind spots:** This is a task-selection and data-quality discipline, not a creative or strategic framework — it tells you *whether* to automate something, not *how* to design the automation itself (pair with `marketing-loops`' own guardrails for that).
