This matters because the private-tier pitch (`PRIVATE_REPO_ACCESS_MODEL.md`) originally described this directory as "proof-of-ROI content" and "real business metrics." That framing was inaccurate as of this note and has been corrected there. Sell these files as **worked examples of the methodology** — genuinely useful for showing a prospective subscriber exactly what an evaluation looks like and how to run one themselves — not as evidence that the framework produced these specific results for anyone.

**When real evaluation data exists** (an actual client's actual before/after numbers), replace the relevant file and remove this caveat for that file specifically — real files should say so explicitly at the top, the way `strategy-skill-eval-2026-08-25.md` and its siblings currently don't need to (since none of them are real yet).
